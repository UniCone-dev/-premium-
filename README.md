# 𓂀 EGYPT ORIGINS — DESERT ORDER

**EGYPT ORIGINS — DESERT ORDER** is a handcrafted KDE Plasma customization project inspired by the timeless beauty of **Ancient Egypt** and the atmospheric world of **Assassin’s Creed Origins**.

The project brings together a complete Egyptian-inspired desktop experience, combining warm desert tones, ancient symbolism, golden accents, atmospheric wallpapers, and carefully designed visual components for KDE Plasma.

## ✦ Features

*  **DESERT ORDER Global Theme**
*  **Custom Icon Theme**
*  **Custom KDE Color Schemes**
*  **Custom Cursor Theme**
*  **Custom Plasma Splash Screen**
*  **Egyptian-inspired Wallpapers**
*  **HTML Animated Wallpapers**
*  **Wallpaper Engine integration**
*  **Custom Desktop Sounds**
*  **Custom Plasma Desktop Layout**

## 𓂀 Design Philosophy

The visual identity of EGYPT ORIGINS draws inspiration from:

* Ancient Egyptian architecture and art
* Pharaohs, temples, hieroglyphics, and desert landscapes
* Egyptian gold, sandstone, and deep desert tones
* The atmosphere and visual identity of *Assassin’s Creed Origins*
* The landscapes of ancient Egypt and the Nile

The goal is to transform KDE Plasma into an immersive **ancient Egyptian desktop environment** while keeping the interface practical and modern.

##  DESERT ORDER

**DESERT ORDER** is the core visual identity of the project — combining ancient Egyptian aesthetics with a modern KDE Plasma desktop.

Every component is designed to work together as part of one cohesive experience rather than as isolated themes.

## Built for KDE Plasma

This project is developed for **KDE Plasma** and is intended to provide a unified customization experience across the desktop.

More components, improvements, optimizations, and compatibility updates will be added as the project evolves.
